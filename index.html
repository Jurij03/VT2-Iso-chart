import SwiftUI import SwiftData struct IsoDetailView: View { @Bindable var record: IsoRecord private var sortedWelds: [Weld] { record.welds.sorted { $0.number < $1.number } } var body: some View { List { ForEach(sortedWelds) { weld in NavigationLink { WeldDetailView(weld: weld) } label: { HStack { Text("Svar \(weld.number)") .font(.headline) Spacer() Text(weld.weldType) .font(.subheadline.weight(.bold)) .padding(.horizontal, 8).padding(.vertical, 3) .background(.quaternary, in: RoundedRectangle(cornerRadius: 6)) statusBadge(weld) } } } } .navigationTitle(record.name) .navigationBarTitleDisplayMode(.inline) } @ViewBuilder private func statusBadge(_ weld: Weld) -> some View { switch weld.status { case "ok": Text("OK").foregroundStyle(.white) .padding(.horizontal, 8).padding(.vertical, 3) .background(.green, in: Capsule()) case "nok": Text("NOK").foregroundStyle(.white) .padding(.horizontal, 8).padding(.vertical, 3) .background(.red, in: Capsule()) default: Text("—").foregroundStyle(.secondary) } } }
